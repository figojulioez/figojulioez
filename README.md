## 🚀 Featured Projects

### 🥩 DagingKu — AI-Based Meat Freshness Detection

An AI-powered mobile application designed to help household consumers identify meat types and assess meat freshness through image classification.

**Technologies:** Python, PyTorch, MobileNetV3, React Native, Expo.

**Focus:** Computer Vision, Deep Learning, Image Classification, and Mobile AI Integration.

[View Repository](https://github.com/figojulioez/DagingKu)

### 🌱 FARI — Smart Agriculture IoT System

An IoT-based smart agriculture system combining ESP32, environmental sensors, and Machine Learning to provide crop recommendations and support automated rainwater harvesting.

**Technologies:** ESP32, Python, Machine Learning, IoT, Sensors.

**Focus:** Smart Agriculture, Predictive Systems, and Hardware-Software Integration.

### 🌾 Plant Leaf Image Classification

A Deep Learning project focused on classifying plant leaf images using Convolutional Neural Networks and image-based learning techniques.

**Technologies:** Python, PyTorch, CNN, NumPy.

**Focus:** Image Classification, Model Training, and Deep Learning.

### 🩺 Ultrasound Image Processing & Segmentation

An exploration of Computer Vision techniques for ultrasound image enhancement and segmentation.

**Technologies:** Python, OpenCV, NumPy.

**Focus:** Image Filtering, Morphological Operations, and Active Contour Segmentation.
